# Ачаа, олголт, хүргэлт, буцаалт

Багцад барааны үндсэн төлбөртэй захиалгууд холбогдоно. Каргоны өртэй гэдгээр
багцаас хасахгүй. Багц, гаргалтын холбоос болон FIFO ирэлтийн тоог уялдуулна.

Ирсэн тоо, олгосон тоо тусдаа. Хэсэгчилсэн ирэлт/олголт дэмждэг.
Олголт нь ирсэн, олгоогүй боломжит тооноос хэтрэхгүй. Давтан хүсэлт нэг олголт болно.
Дутуу ирэлтийн каргоны алдаатай хуваарилалт болон давхар олголтыг lock-оор хамгаална.

Карго Итгэлийн орлого. Админ олгох/хүргэх үйлдлээр мөнгө автоматаар нэмэхгүй.
Хэрэглэгч төлбөрийн холбоосоор төлнө; зөвшөөрсөн онцгой банкны орлогыг ADMIN бүртгэнэ.

Хүргэлт: хүсэлт → админ батлах → жолооч/хүргэлтэд оноох → хүргэсэн.
Олголтын баримт, тоо, дэвтэр нэг үйл явдлыг давхар нэмэхгүй.

Цуцлалт, барааны буцаалт, мөнгөний буцаалт тусдаа ойлголт.
Олгосон мөрийг шууд цуцлахгүй. Буцаалт бодит авсан цэвэр орлогоос хэтрэхгүй;
лизингийн мөнгөний буцаалтад каргоны SHOP орлогыг ашиглахгүй.
