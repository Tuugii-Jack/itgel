# Байршуулалт ба шалгалт

Код: GitHub `Tuugii-Jack/itgel`, main. Хэрэглэгч main-д илгээх, deploy хийхийг зөвшөөрсөн.
Backend/API болон frontend хоёр тусдаа Vercel project. Тохиргоонд `hnd1` бүс.

Monorepo root-оос backend deploy хийхэд `--local-config backend/vercel.json --regions hnd1`,
frontend-д `--local-config frontend/vercel.json --regions hnd1` заана.
Build machine-ийн бүс нь function-ийн бүсээс өөр байж болно; function metadata/health-ээр шалгана.
Production архивт `.env`, dependency, DB dump, тест/хувийн файлыг оруулахгүй.

Шалгалт: TypeScript, шаардлагатай backend tests, frontend helper tests, өөрчилсөн UI-ийн lint,
хоёр build, эрхийн сөрөг кейс, transaction/replay, өөр өөр QPay merchant, дэвтэр/үлдэгдлийн audit.
Зөвхөн тусгаарласан тестийн DB-д хиймэл SMS/банкны хариу ашиглана.
Production probe нь төлбөргүй QA invoice үүсгээд шалгаж цуцална; жинхэнэ мөнгө/SMS явуулахгүй.
