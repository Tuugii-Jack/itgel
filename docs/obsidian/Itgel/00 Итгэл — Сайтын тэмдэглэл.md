## Одоогийн ажил — 2026-10-13

Захиалгын жагсаалт болон доторх дэлгэрэнгүйг энгийн болгосон. Одоогийн хайлт,
шүүлт, экспорт, төлөв, багц, олголт, цуцлалт, QPay, буцаалт хадгалагдсан.
Дансны орлогыг зөвхөн ADMIN бүртгэнэ. Энэхүү эрхийн шинэ дүрэм нь өмнөх
лизингийн админд дансны бүртгэл зөвшөөрсөн дүрмийг орлоно.

15 тэмдэглэлд сайтын урсгал, 204 API зам, 42 model/enum бүтцийг холбосон.
Тэмдэглэл нь кодтой хамт хадгалагдаж, хэрэглэгчийн Obsidian сангийн `Itgel` хавтастай
синк хийнэ. Хэрэглэгч тэмдэглэлээ өөрчилсөн бол эхлээд нэгтгэнэ; дарж бичихгүй.

Шинэчлэлт сайтад байршуулсан. 560 backend + 81 frontend шалгалт давсан.
Production эрх, QPay, сангийн тулгалтын дэлгэрэнгүй: [[12 Өөрчлөлтийн түүх]].

Нууц түлхүүр, токен, бодит хэрэглэгчийн утас/хаяг, сангийн dump энд хадгалахгүй.
