# SMS ба мэдэгдэл

Дэлгүүрийн OTP/ирэлтийн SMS болон лизингийн SMS тусдаа CallPro түлхүүр/илгээгчтэй.
OTP, ирэлтийн мэдэгдэл, чөлөөт SMS, төлөлтийн хуваарийн сануулга дэмжинэ.

Бөөн илгээлт: эцсийн текстийг preview → хүн батлах → 8 хүлээн авагчаар хүсэлт →
сервер дээр 4 хүртэл илгээлт зэрэг. Явц харуулна. Тасарсан хүсэлт дараагийн хэсгийг зогсооно.
Ижил баталгаажуулалтын sendKey-г дахин оролдоход хадгалж, өмнөх delivered SMS-ийг ч давхар явуулахгүй.

`queued/pending` = үйлчилгээ хүлээн авсан/хүлээгдэж буй. `delivered` = тайлангаар хүргэгдсэн.
`failed` = батлагдсан алдаа; `unknown` = тодорхойгүй. Timeout-ийг хүргэгдсэн гэж үзэхгүй.
8 секундын хязгаар нь headers болон response body-д үйлчилнэ.

SMS бүр эхлээд DB-д бүртгэгдэнэ. Үйлчилгээний message_id болон үр дүнг хадгална.
Cron хүргэлтийн төлөвийг шалгадаг; шинэ SMS дахин явуулдаггүй.
40/цагийн limiter нь ижил confirmation replay-ийг дахин зарцуулахгүй.

Код: `services/sms.ts`, `services/smsDispatch.ts`, `services/smsDeliveryJob.ts`, `frontend/lib/smsBatch.ts`.
