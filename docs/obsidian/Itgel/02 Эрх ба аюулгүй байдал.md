# Эрх ба аюулгүй байдал

| Эрх | Үндсэн зорилго | Дансны орлого бүртгэх — шинэ дүрэм |
|---|---|---|
| CUSTOMER | Өөрийн захиалга, QPay | Хориглоно |
| STAFF | Үндсэн админд харах, олголт | Хориглоно |
| LEASING | Өөрийн лизингийн ажил | Хориглоно |
| OWNER | Дэлгүүр/лизингийн нийт хяналт | Хориглоно |
| ADMIN | Үндсэн админы ажил | Зөвшөөрнө |

2026-10-13-ны хэрэглэгчийн шинэ заавар: дансны орлогыг зөвхөн ADMIN бүртгэнэ.
Өмнөх LEASING-only дүрмийг орлоно. Энэ нь бодит шилжүүлэг хийх бус, орсон мөнгийг
дэвтэрт тэмдэглэх эрх. Буцаалтын одоогийн урсгалыг тусад нь хадгална.

- Сервер JWT-ийн role-д дангаар нь итгэхгүй: идэвх, эрх, tokenVersion, нэвтрэх утсыг DB-ээс шалгана.
- Нэг хүсэлтийн давхар guard нэг баталгаажуулалт хэрэглэнэ. Шинэ HTTP хүсэлтэд дахин шалгана.
- LEASING өөрийн operator/owner хүрээний захиалга, бараа, тооцоог л харна.
- Хэрэглэгч өөрийн захиалгаас бусдыг уншихгүй. Төлбөрийн холбоос нь админ эрх олгохгүй.
- UI товч нуух нь хамгаалалт биш; бүх бичих API дээр эрхийг шалгана.
- Нууц, бодит хэрэглэгчийн мэдээллийг тэмдэглэлд хадгалахгүй.

Код: `backend/src/middleware/auth.ts`, `lib/adminRoles.ts`, `lib/leasingAccess.ts`.
