# Өөрчлөлтийн түүх

## 2026-10-13 — Захиалгын дизайн, ADMIN дансны орлого, Obsidian

Төлөв: хэрэгжүүлсэн; production байршуулалтын баталгаажуулалт хүлээгдэж байна.

Хэрэглэгчийн хүсэлт:
- Захиалгын жагсаалт болон доторх дизайныг энгийн, харахад хялбар болгох.
- Одоогийн үйлдлүүдийг хадгалах.
- Дансны орлогыг зөвхөн ADMIN бүртгэх; лизингийн админ, бусад хүн бүртгэхгүй.
- Сайтын бүх хэсгийн тэмдэглэлийг Obsidian-д хөтлөх.

Жагсаалтыг 5 үндсэн бүлэг багана болон утасны карттай болгосон. Дэлгэрэнгүйд
хэрэглэгч/огноо/явц, үлдэгдэл/орлого/нийт, төлбөр/бараа/түүхийг ялгаж байрлуулсан.
Өмнөх хайлт, шүүлт, бөөн үйлдэл, экспорт, төлөв, олголт, QPay, буцаалт хадгалагдсан.

Дансны орлогыг зөвхөн ADMIN үндсэн порталаас бүртгэнэ. Дүн/хүлээн авагчийн cap,
заавал гүйлгээний дугаар, зэрэг хүсэлт ба дахин бүртгэлийн хамгаалалттай.
Лизингийн дансны бүртгэлийг үндсэн админд шилжүүлж, Итгэлийн тооцооны үүсгэх/батлах
эрхийг мөн ADMIN-д хязгаарласан. Хэрэглэгч ба лизингийн админы QPay хэвээр.
Буцаалт нь орлого биш; өмнөх эрхийн урсгалыг өөрчлөөгүй. Schema migration байхгүй.

Obsidian сангийн бүтэц болон 15 холбогдсон тэмдэглэл үүсгэв.
204 API зам, 42 model/enum бүтцийг кодоос үүсгэх лавлах нэмэв.
Root AGENTS.md-д өөрчлөлт бүрийн тэмдэглэлийг шинэчлэх заавар нэмэв.
Хэрэглэгчийн одоо нээсэн Obsidian Vault-ийн Itgel хавтаст синк хийж, native Obsidian-д
index-ийг нээж шалгасан. Бусад тэмдэглэлд хүрэхгүй; хэрэглэгчийн өөрчлөлттэй зөрчилдвөл
синк зогсож нэгтгэх шаардлагатайг мэдэгдэнэ.

Шалгалт: 560 backend, 81 frontend; TypeScript, өөрчилсөн UI lint, хоёр build.
Бодит HTTP + тусгаарласан PostgreSQL дээр захиалга → ADMIN банк → олголт,
лизинг/QPay/карго/хэсэгчилсэн олголт, эрхийн хориг, давхар гүйлгээ, өр хаалт,
QPay дугаарыг банк гэж давхар нэмэхгүйг шалгасан.
Тестийн орчинд банк/SMS transport хиймэл; жинхэнэ мөнгө/SMS явуулаагүй.
Production эрхийн probe, QPay-ийн төлбөргүй шалгалт, дэвтрийн audit-ийг deploy-ийн дараа бичнэ.
Вэбийн браузерын харагдацын шалгалт энэ орчинд хийх боломжгүй тул хийсэн гэж үзэхгүй.
