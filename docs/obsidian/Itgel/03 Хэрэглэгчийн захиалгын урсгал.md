# Хэрэглэгчийн захиалгын урсгал

1. Бараа/гаргалт сонгож хэмжээ, өнгө зэрэг сонголт болон тоогоо оруулна.
2. Утасны OTP-оор нэвтэрч, захиалга үүсгэнэ. Шинэ захиалгад мөнгө автоматаар нэмэхгүй.
3. Төлбөрийн холбоос `/t/<code>` болон өөрийн захиалгаас QPay төлнө.
4. Сервер банкны төлбөрийг шалгаж, төлбөрийн дэвтэрт нэг удаа нэмнэ.
5. Админ баталгаа, багц/ачаа, ирэлтийг ажиллуулна.
6. Бараа ирэхэд админ SMS явуулна. SMS нь зөвхөн товчоор баталсны дараа явна.
7. Карго/бусад үлдэгдлийг зөв хүлээн авагчид төлнө.
8. Олголт эсвэл хүргэлтээр барааг хүлээн авна. Хэсэгчилсэн ирэлт/олголт дэмжигдэнэ.

Лизингийн шимтгэл ба үндсэн төлбөр — лизингийн QPay. Дэлгүүрийн бараа, карго,
агуулах — Итгэлийн QPay. Дансны гүйлгээ орсон онцгой тохиолдолд ADMIN бүртгэнэ;
хэрэглэгчийн апп дотор дансны төлбөрийг баталсан гэж тэмдэглэх эрх байхгүй.

Дэлгэрэнгүй: [[05 Төлбөр ба тооцоо]], [[08 Ачаа олголт хүргэлт буцаалт]].
