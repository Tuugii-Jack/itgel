# Сайтын бүтэц

Итгэл нь урьдчилсан захиалга, бэлэн бараа, лизинг, ачааны ирэлт, олголт болон хүргэлтийг нэг захиалгад холбодог.

| Хэсэг | Зориулалт |
|---|---|
| Хэрэглэгчийн дэлгүүр | Бараа, сагс, захиалга, QPay, профайл, захиалгын төлөв |
| Үндсэн админ `/workspace/shop` | Захиалга, бараа/гаргалт, багц, олголт, хүргэлт, хэрэглэгч, буцаалт, тайлан, тохиргоо |
| Лизингийн админ `/workspace/leasing` | Өөрийн захиалга, төлөлтийн хуваарь, SMS, бэлэн бараа/борлуулалт, Итгэлд төлөх |
| API `api.itgelshop.mn` | Серверийн эрх, төлбөр/үлдэгдэл, QPay болон SMS интеграц |

Frontend: Next.js 16.3, React. Backend: Express, TypeScript, Prisma, PostgreSQL.
Зураг: R2/Supabase; QPay болон дэлгүүр/лизингийн SMS хоёр тусдаа тохиргоотой.

Админ цэсийг эрхээр хязгаарлана. Лизингийн админ үндсэн админы хэсэг рүү шилжихгүй.
OWNER тусдаа эрхтэй; мөнгөний тусгай үйлдлийг ерөнхий админ эрхээс салгаж шалгана.

Код: `frontend/app`, `frontend/features`, `backend/src/routes`, `backend/src/services`.
